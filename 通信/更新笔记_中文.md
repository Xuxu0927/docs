# 在 GitHub 更新笔记（示例）

## 修改现有内容

直接编辑本文件并提交，下载内容会随 Pages 部署更新。首页是下载目录，不展示正文。

## 修改网站标题、主题或分类

打开根目录 README.md：

- 修改 `# 学习笔记` 可修改网站标题。
- 修改 `## 实践记录` 可修改分类名称。
- 修改表格第二列的“在 GitHub 更新笔记”可修改主题名称。
- 复制一个 `## 分类标题` 和六列表格，即可添加分类。
- 复制表格的一行并修改文件链接，即可添加笔记。

## 上传自己的文件

一个分类一个文件夹，文件直接平放，不分语言或格式。例如：

```text
机器学习/
  线性回归_中文.md
  线性回归_English.md
  线性回归_中文.pdf
```

将文件上传后，在 README 对应表格中添加一行：

```markdown
| 1 | 线性回归 | [MD](机器学习/线性回归_中文.md) | [MD](机器学习/线性回归_English.md) | [PDF](机器学习/线性回归_中文.pdf) | — |
```

没有的版本填 `—`。文件路径必须和实际文件一致。

提交后等待 Pages 完成部署，刷新网站。完整说明见根目录“使用说明.md”。
