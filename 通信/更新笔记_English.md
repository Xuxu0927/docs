# Updating Notes on GitHub (Example)

Edit README.md directly to update the website. Its first `#` heading is the site title, `##` headings are categories, and the second table column is the topic name. Copy a category heading and its six-column table to create a category; copy a table row to add a note.

Upload every file directly into its category folder. Keep Markdown, PDFs, Chinese and English versions side by side. Use relative links in the table, such as `[MD](机器学习/线性回归_中文.md)`. Missing versions use `—`.

Edit an existing Markdown file or replace a PDF at the same path to update its contents. Commit your changes, wait for Pages to deploy, then refresh the website. No JSON, backend or local build command is needed.

README.en.md optionally supplies English labels; match entries using identical document links. Chinese README controls which categories and notes appear.
