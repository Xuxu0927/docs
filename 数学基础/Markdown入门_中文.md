# Markdown 入门（示例）

这是一篇示例笔记，属于“基础知识”。可以直接修改本文件，或用自己的笔记替换它。

## 标题和段落

用 `#` 写一级标题，用 `##` 写二级标题。段落之间空一行。

## 列表

- 今天学习的概念
- 一个具体例子
- 还没有理解的问题

## 代码

```python
message = "Hello, notes!"
print(message)
```

## 表格

| 概念 | 含义 |
| --- | --- |
| Markdown | 文本笔记格式 |
| GitHub Pages | 发布本仓库的网页 |

## 修改网站显示

直接编辑根目录 README.md：第一行是网站标题，`##` 开头的行是分类标题，表格第二列是主题名称。

本笔记的中文和英文文件都平放在“基础知识”文件夹内。PDF 也可放在同一文件夹，不需要另建格式或语言子文件夹。

详细步骤见根目录的“使用说明.md”。
