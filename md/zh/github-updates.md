# 在 GitHub 更新笔记（示例）

这是一篇“实践记录”示例，演示如何维护本网站。两个分类只是示例，可以改成你自己的分类名称。

## 1. 修改已有笔记

1. 在 GitHub 打开相应的 `.md` 文件。
2. 点击编辑按钮，修改内容。
3. 点击 **Commit changes** 提交。
4. 等待 Pages 部署完成，网站的下载文件就会更新。

网页目前是分类下载目录，不会把 Markdown 正文直接展示在首页。GitHub 仓库内可以预览正文。

## 2. 新增一篇笔记

1. 将中文笔记上传到 `md/zh/`，例如 `md/zh/my-note.md`。
2. 如果有英文版，上传到 `md/en/`。
3. 在根目录 `notes.json` 的数组中追加一条记录；与前一条之间加逗号：

```json
{
  "category": { "zh": "实践记录", "en": "Practice" },
  "title": { "zh": "我的新笔记", "en": "My New Note" },
  "md_zh": "md/zh/my-note.md",
  "md_en": null,
  "pdf_zh": null,
  "pdf_en": null
}
```

上面的路径只是格式示例，必须先上传实际文件，才能下载。

## 3. 调整分类

- 相同的 `category.zh` 会合并为同一张分类表格。
- 修改 `category.zh` 和 `category.en` 可以修改中英文分类名。
- 新增不同的分类名，就会出现新的分类表格。
- 分类按第一次出现的顺序排列；同一分类中的笔记按数组顺序排列。
- 不填写 `category` 的旧笔记仍可显示；与其他分类并列时会归入“其他”。

## 4. 上传 PDF

将文件放入 `pdf/zh/` 或 `pdf/en/`，再填写 `pdf_zh` 或 `pdf_en`。上传 PDF 不会自动生成英文版；中英文文件需要分别准备。

## 5. README 与网站的关系

网站自动读取 `notes.json`。README 中的分类表格是仓库首页说明，不是网站的数据源。

若同时维护 README，可以手动改表格；也可以在本地运行 `python tools/build.py`，从清单生成中英文 README。网站更新本身不需要运行这个命令。

## 6. 删除示例

理解后，可以从 `notes.json` 移除这两篇示例的记录，再删除对应 MD 文件，换成自己的内容。
