01 / 连接仓库

先连接你的 GitHub

使用仅授权 docs 仓库的令牌。令牌只在当前页面中使用，刷新或关闭页面后需重新输入。

令牌只发送给 GitHub，不会存入仓库或浏览器存储。
第一次使用？按这 3 步创建令牌
  1. 打开 GitHub 令牌设置 ↗，设置名称和有效期。
  2. Resource owner 选 Xuxu0927；Repository access 选 Only select repositories → docs。
  3. Repository permissions 中，将 Contents 设为 Read and write，生成后复制到左侧。

这里只需要仓库内容权限。令牌过期后，重新创建即可。
